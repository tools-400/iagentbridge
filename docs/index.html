iAgentBridge Plug-in

Hi, this is the home of the iAgentBridge plug-in for IBM Rational Developer for i.

 Version: 1.1.0.b001

Introduction

iAgentBridge is an open source plug-in for IBM Rational Developer for i. It runs a server of the Model Context Protocol (MCP) inside RDi, so that AI agents like Claude Code can use functions of RDi, with the settings that apply in RDi.

The iAgentBridge Project Team


Tools/400, Thomas Raddatz

Features

  • Runs Source > Clean Up on Java files with the clean-up profile of the project or of the workspace, including the formatter.
  • Tells the agent, which RDi, workspace and Java projects it talks to.
  • Other plug-ins can add tools, e.g. format_rpg of iRPGFormatter, which formats RPG sources with the settings of RDi.
  • Preference page with the port, the token and the command, that registers the server in Claude Code.
  • Listens on 127.0.0.1 only and requires a token.
  • One server per RDi instance; RDi 9.6, 9.8 and 9.9 get different default ports.
